# 📄 AI Resume Analyzer

An AI-powered resume analyzer that matches your resume 
with job descriptions and gives ATS score instantly.

## 🔗 Live Demo
[👉 Click here to try it live](https://ai-resume-analyzer-bxddf8rlhrfyej88zfhvff.streamlit.app/)

## ✨ Features
- 📊 ATS Match Score (Weighted Algorithm)
- ✅ Skills Gap Analysis
- 🔥 Matching Skills Detection
- 💡 AI Resume Improvement Suggestions
- 🎤 AI Generated Interview Questions
- 🎯 Interview Probability Prediction
- 📥 Download Report

## 🛠️ Tech Stack
- **Frontend** → Streamlit
- **Backend** → Python
- **NLP** → TF-IDF + Cosine Similarity
- **ML** → Scikit-learn
- **AI** → Groq LLM (Qwen)
- **Charts** → Plotly
- **Deployment** → Streamlit Cloud

## 📦 Installation
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 🚀 How it Works
1. Upload your Resume PDF
2. Paste Job Description
3. Click Analyze
4. Get ATS Score + AI Insights
